# Figures for the certification note

The three main figures are regenerated by `docs/make_figures.py` from the selected certificate bounds and the Round 4 cold-start records. The figures contain no internal filenames or historical fitted curves.

- **headline.png / headline.svg:** “Certified local approximations to triangle-network correlations.” Each positive point is an upward-rounded bound `U >= ||P-Q||₂` for an exactly local finite witness. Exact zeros occupy a separate column explicitly marked “0 — exact.” Renou noise rows use `u²=0.85`. A noiseless endpoint is one target, irrespective of the continuation path that produced a candidate. The selected development witnesses are separate from timed comparison runs.
- **baseline-time.png / baseline-time.svg:** One panel for each common target, with all three methods and all ten runs at 10 and 60 seconds. The legend identifies LHV-Net-2020 as the small CPU configuration (eager TensorFlow wrapper). Vertical coordinate is the raw L2 norm to the same saved 64-entry target, without variance correction or truncation. Neural error bars are approximate 95% fresh held-out basic block-bootstrap intervals, with both endpoints clipped at zero; finite-model values are full contractions. Horizontal jitter separates overlapping observations; it is not a change in budget. The dotted line is the predeclared success threshold `10⁻³`. There are no interpolated curves or unmeasured budgets.
- **local-model.png / local-model.svg:** A compact box for the Renou detector witness at `u²=0.85, v=0.93`: exact trimming from `(12,12,12)` to `(8,9,2)`, original-target bound, compressed size and checking time. The timer includes rational model parsing, simplex checks, exact contraction, distances, symmetry and hashes; gzip/JSON loading and prior target parsing are excluded. Cardinalities are not claimed minimal.

The configuration study is now a small table with separate additional and total times in the note and RESULTS.md. It is an illustrative earlier study, not an equal-budget ablation. The former configuration chart has been retired from the showcase.
