# Round 3 changes

Round 3 follows the referee review in `ORACLE-REVIEW.txt` and keeps the work
downstream of the pinned `triangle-local` clone. No upstream repository, CI,
release workflow, publication, or external message was changed.

## Scientific framing and target metric

- Reframed the package around exact certification, inspectable finite
  witnesses, source-independence checks, reproducible target conventions, and
  search-to-certificate workflows. Finite local-model search is credited to
  da Silva–Parisio (2023), and the current Girardin et al. (2026) neural
  toolbox is recorded as literature context.
- Corrected the 2020 citation: published Eq. (3) is the KL objective; the
  Euclidean distance used in this repository is defined in the Results text.
  Eq. (4) remains historical fitted context and is not used for headline
  improvement factors.
- Added `benchmarks/target_bounds.py` and the 47-record
  `benchmarks/target-bounds.json` receipt. For intended target `P`, stored
  rational target `P_stored`, and certified model output `Q`, the checker
  establishes exact `E = ||P_stored-Q||_2^2`, interval bounds
  `delta_target >= ||P-P_stored||_2`, and the upward-rounded principal metric
  `U = sqrt(E) + delta_target`.
- Updated README and RESULTS tables to show `delta_target`, `U`, target
  identity, and the distinction between a certified nearby local model and an
  exact target witness.

## Baselines and reproducibility

- Added `BENCHMARK.md`, generated by `benchmarks/write_benchmark.py`, with the
  frozen six-point protocol, MacBook Pro/M2 Pro resource cap, target/noise
  conventions, seeds, solver revisions, medians and min–max spreads at 10 s
  and 60 s, and honest `not reached` entries for the unrun 300 s arm.
- Ran two fresh blind repetitions of the public LHV-Net 2020 code and two
  fresh blind `localmodels` trials on each stress point. LHV-Net scores are
  independently evaluated 4096-sample L2 observations; `localmodels` scores
  use its full finite contraction, with native RMS = L2/8 retained in the raw
  receipt. The Girardin toolbox was not run because no pinned executable
  checkout was available in this task.
- Added the external run scripts and immutable receipts under
  `benchmarks/external/`, including revisions, checkpoint times, seeds, peak
  RSS, and timeout status.

## Neural extraction and local polishing

- Added `benchmarks/external/extract_lhv.py` and receipts for a frozen LHV-Net
  model at Renou detector `u²=0.85, v=0.93`. Independent four-point supports
  per source and full Cartesian contraction produce a certified finite model;
  triangle-local convex polishing reduces its certified stored-target L2 from
  `0.0480933910` to `0.0035721118` in `1.903` additional seconds.

## Witnesses and monotonicity
